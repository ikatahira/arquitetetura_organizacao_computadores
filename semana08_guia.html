🔵 Primeiros Passos no PowerShell

🔬 Laboratório ⏱ 30 min

📋 Enunciado

Abra o PowerShell e execute uma série de cmdlets básicos, observando e documentando os resultados de cada um. Ao final, crie uma tabela comparando PowerShell e CMD.

Anotação dos resultadosSem anotaçõesAnotações superficiaisAnotações clarasExplicou o que cada comando faz com suas palavras
Tabela ComparativaAusenteIncompletaCompleta com erros mínimosCompleta, organizada e com exemplos extras
Nomenclatura do ArquivoNome erradoNome parcialmente corretoNome corretoNome correto + organizado

✅ Resolução Passo a Passo

🚀 Antes de começar — Abrindo o PowerShell como Administrador
  • 1
    Pressione Win + X (segurar a tecla do Windows e apertar X ao mesmo tempo). Um menu escuro aparece no canto inferior esquerdo.
  • 2
    Clique em "Terminal (Administrador)" no menu que aparecer:
    ⚙️ Gerenciador de Dispositivos
    💾 Gerenciamento de Disco
    🖥️ Terminal (Administrador) ← clique aqui
    📋 Gerenciador de Tarefas
  • 3
    Uma janela azul de confirmação vai aparecer (UAC). Clique em "Sim":
    🛡️Controle de Conta de Usuário
    Deseja permitir que este aplicativo faça alterações no seu dispositivo?

    Windows PowerShell
    Fornecedor verificado: Microsoft Windows

  • 4
    O PowerShell vai abrir. Confirme que aparece "Administrador:" na barra de título:
    ✅ Administrador: Windows PowerShell ← confirme isso!
    Windows PowerShell Direitos autorais (C) Microsoft Corporation. Todos os direitos reservados.  
    PS C:\Windows\System32>

    ✅ Pronto! Se a barra de título mostra "Administrador:" você está no lugar certo. Agora pode digitar os comandos!

⌨️ Executando os Cmdlets — Um por Um
  • 1
    Ver em qual pasta você está agora
    Digite o comando abaixo e pressione Enter:
    Administrador: Windows PowerShell
    PS C:\Windows\System32> Get-Location
      Path ---- C:\Windows\System32  
    PS C:\Windows\System32>

    📌 O que você vê: a pasta atual onde o PowerShell está trabalhando. É como o cd do CMD — mas com mais informação!

  • 2
    Navegar para a raiz do disco C:
    Administrador: Windows PowerShell
    PS C:\Windows\System32> Set-Location C:\
     
    PS C:\>

    📌 Repare: o prompt mudou de C:\Windows\System32> para C:\> — isso confirma que você se moveu para a raiz do C:. É o mesmo que cd C:\ no CMD.

  • 3
    Listar arquivos e pastas do diretório atual:
    Administrador: Windows PowerShell
    PS C:\> Get-ChildItem
      Directory: C:\   Mode LastWriteTime Length Name ---- ------------- ------ ---- d---- 01/04/2026 10:23 PerfLogs d-r-- 15/04/2026 08:44 Program Files d-r-- 15/04/2026 08:44 Program Files (x86) d-r-- 27/04/2026 07:30 Users d-r-- 27/04/2026 07:30 Windows  
    PS C:\>

    📌 Mode = tipo (d = diretório/pasta, - = arquivo). LastWriteTime = última modificação. Name = nome da pasta ou arquivo. É o mesmo que dir no CMD!

  • 4
    Ver também os arquivos ocultos:
    Administrador: Windows PowerShell
    PS C:\> Get-ChildItem -Hidden
      Directory: C:\   Mode LastWriteTime Length Name ---- ------------- ------ ---- d--h- 15/04/2026 08:44 $Recycle.Bin d--h- 01/04/2026 10:22 System Volume Information ---h- 27/04/2026 07:31 512 hiberfil.sys ---h- 27/04/2026 07:30 16384 pagefile.sys  
    PS C:\>

    📌 O "h" no Mode significa "hidden" (oculto). Esses arquivos normalmente não aparecem no Windows Explorer. O $Recycle.Bin é a Lixeira!

  • 5
    Navegar até a pasta System32:
    Administrador: Windows PowerShell
    PS C:\> Set-Location C:\Windows\System32
     
    PS C:\Windows\System32>
  • 6
    Contar quantos arquivos .exe existem no System32:
    Administrador: Windows PowerShell
    PS C:\Windows\System32> Get-ChildItem *.exe | Measure-Object
      Count : 516 Average : Sum : Maximum : Minimum : Property :  
    PS C:\Windows\System32>

    📌 O | (pipe) manda o resultado de Get-ChildItem para o Measure-Object contar. O número vai variar no seu computador — pode ser diferente do print!

  • 7
    Ver informações do computador:
    Administrador: Windows PowerShell
    PS C:\Windows\System32> Get-ComputerInfo | Select-Object OsName, TotalPhysicalMemory
      OsName TotalPhysicalMemory ------ ------------------- Microsoft Windows 11 Pro 8455016448  
    PS C:\Windows\System32>

    📌 TotalPhysicalMemory aparece em bytes. Para converter: 8.455.016.448 ÷ 1.073.741.824 ≈ 7,87 GB de RAM. O seu número vai ser diferente!

  • 8
    Ver os 10 processos que mais consomem CPU:
    Administrador: Windows PowerShell
    PS C:\Windows\System32> Get-Process | Sort-Object CPU -Descending | Select-Object -First 10
      Handles NPM(K) PM(K) WS(K) CPU(s) Id SI ProcessName ------- ------ ----- ----- ------ -- -- ----------- 892 45 98432 148322 1823,47 4120 1 chrome 445 31 8192 24576 18,23 3560 1 powershell 312 22 5104 18234 12,45 2340 1 msedge 234 18 4096 12800 8,12 1820 1 SearchHost ... (continua até 10 processos) ...  
    PS C:\Windows\System32>

    📌 O processo com maior CPU(s) aparece primeiro. Sort-Object CPU -Descending ordena do maior para o menor. Select-Object -First 10 mostra só os 10 primeiros.

🚨 Erros Comuns e Como Resolver:

Erro: O termo 'Get-ChildItem' não é reconhecido
Causa: Você digitou errado — talvez esqueceu o hífen ou errou uma letra.
Solução: Escreva exatamente Get-ChildItem (G maiúsculo, C maiúsculo, I maiúsculo)

Erro: Acesso negado ou Access is denied
Causa: Você abriu o PowerShell sem ser Administrador.
Solução: Feche e abra de novo com botão direito → Executar como Administrador

🟣 Navegação pelo Sistema via PowerShell

🔬 Laboratório ⏱ 35 min

📋 Enunciado

Use os comandos de navegação do PowerShell para explorar o sistema de arquivos, criar uma pasta e um arquivo de texto dentro dela, tudo pela linha de comando.

📊 Rubrica de Avaliação
CritérioInsuficiente (0–5)Básico (6–7)Proficiente (8–9)Excelente (10)
Navegação entre pastasNão navegouNavegou com errosNavegou corretamenteNavegou com fluência e sem erros
Criação de pasta/arquivoNão criouCriou parcialmenteCriou corretamenteCriou e verificou com Get-ChildItem
DocumentaçãoSem registroRegistro mínimoBem documentadoPrints + explicações de cada etapa
Nomenclatura do ArquivoNome erradoParcialmente corretoNome corretoNome correto + organizado

✅ Resolução Passo a Passo

🗺️ Navegando pelo Sistema de Arquivos
  • 1
    Ir para a pasta de usuários:
    Administrador: Windows PowerShell
    PS C:\> Set-Location C:\Users
    PS C:\Users>
  • 2
    Ver o que tem dentro da pasta Users:
    Administrador: Windows PowerShell
    PS C:\Users> Get-ChildItem
      Directory: C:\Users   Mode LastWriteTime Length Name ---- ------------- ------ ---- d-r-- 27/04/2026 07:30 Aluno d-r-- 01/04/2026 10:22 Default d-r-- 01/04/2026 10:22 Public  
    PS C:\Users>

    📌 O nome da sua pasta de usuário vai ser diferente — pode ser seu nome, "aluno", ou o nome do computador da escola.

  • 3
    Ir para a pasta Desktop (Área de Trabalho) do seu usuário:
    Troque "Aluno" pelo nome da sua pasta!
    Administrador: Windows PowerShell
    PS C:\Users> Set-Location C:\Users\Aluno\Desktop
     
    PS C:\Users\Aluno\Desktop>

    💡 Atalho: Você também pode digitar Set-Location ~\Desktop — o ~ representa automaticamente sua pasta de usuário!

📁 Criando Pasta e Arquivo pela Linha de Comando
  • 4
    Criar uma pasta chamada "MinhasAulas" no Desktop:
    Administrador: Windows PowerShell
    PS C:\Users\Aluno\Desktop> New-Item -Name "MinhasAulas" -Type Directory
      Directory: C:\Users\Aluno\Desktop   Mode LastWriteTime Length Name ---- ------------- ------ ---- d---- 27/04/2026 09:15 MinhasAulas  
    PS C:\Users\Aluno\Desktop>

    ✅ A pasta MinhasAulas foi criada! Você pode abrir o Windows Explorer e confirmar que ela apareceu no Desktop.

  • 5
    Entrar na pasta que acabou de criar:
    Administrador: Windows PowerShell
    PS C:\Users\Aluno\Desktop> Set-Location MinhasAulas
    PS C:\Users\Aluno\Desktop\MinhasAulas>
  • 6
    Criar um arquivo de texto dentro da pasta:
    Administrador: Windows PowerShell
    PS C:\...\MinhasAulas> New-Item -Name "anotacoes.txt" -Type File
      Directory: C:\Users\Aluno\Desktop\MinhasAulas   Mode LastWriteTime Length Name ---- ------------- ------ ---- -a--- 27/04/2026 09:18 0 anotacoes.txt  
    PS C:\...\MinhasAulas>
  • 7
    Confirmar que o arquivo foi criado (listar o conteúdo da pasta):
    Administrador: Windows PowerShell
    PS C:\...\MinhasAulas> Get-ChildItem
      Directory: C:\Users\Aluno\Desktop\MinhasAulas   Mode LastWriteTime Length Name ---- ------------- ------ ---- -a--- 27/04/2026 09:18 0 anotacoes.txt  
    PS C:\...\MinhasAulas>

    ✅ Parabéns! Você criou uma pasta e um arquivo usando só a linha de comando — sem clicar em nada! Documente essa conquista com um print da tela.

  • 8
    Voltar uma pasta (ir para o diretório pai):
    Administrador: Windows PowerShell
    PS C:\...\MinhasAulas> Set-Location ..
    PS C:\Users\Aluno\Desktop>

    📌 O .. (dois pontos) significa "pasta acima". É igual ao CMD! Funciona em todos os sistemas.

  • 9
    Salve seu relatório:
    Documente todos os prints e salve como sem08_ex2_SeuNome.docx

💡 Dica: Use a tecla Tab para autocompletar nomes de pastas! Digitou Set-Location Min e aperta Tab → completa para Set-Location MinhasAulas automaticamente!

🚨 Erro comum: Set-Location: Não foi possível localizar o caminho especificado
Causa: Você tentou entrar em uma pasta que não existe ou digitou o nome errado.
Solução: Use Get-ChildItem primeiro para ver os nomes exatos das pastas disponíveis, depois tente de novo.

Usou Get-ChildItem para listar pastas em pelo menos 3 lugares diferentes
Criou a pasta "MinhasAulas" no Desktop com New-Item
Criou um arquivo .txt dentro da pasta com New-Item
Confirmou a criação com Get-ChildItem
Usou ".." para voltar uma pasta

🟢 Configurando o Perfil do PowerShell

🔬 Laboratório ⏱ 25 min ⚠️ Atenção: requer Administrador

📋 Enunciado

Configure o ambiente PowerShell com um perfil personalizado que carrega aliases e funções úteis automaticamente toda vez que você abre o PowerShell.

📊 Rubrica de Avaliação
CritérioInsuficiente (0–5)Básico (6–7)Proficiente (8–9)Excelente (10)
DiagnósticoNão verificou políticaVerificou sem interpretarVerificou e entendeuDiagnóstico preciso e documentado
Criação do PerfilNão criouCriou com errosCriou corretamenteCriou e confirmou funcionamento
Aliases FuncionaisAliases não funcionamUm alias funcionaDois aliases funcionamTodos funcionam + adicionou extras
DocumentaçãoSem registroRegistro mínimoBem documentadoPrints + explicação de cada etapa

✅ Resolução Passo a Passo

⚠️ Antes de começar: Este exercício precisa do PowerShell aberto como Administrador. Se não tiver aberto assim, feche e abra novamente com botão direito → Executar como Administrador.

🛡️ Passo 1 — Verificar e Configurar a Política de Execução
  • 1
    Verificar qual política está ativa agora:
    Administrador: Windows PowerShell
    PS C:\> Get-ExecutionPolicy
      Restricted  
    PS C:\>

    📌 O que significa cada resposta:
    Restricted = nenhum script pode rodar → faça o Passo 2
    AllSigned = só scripts assinados → faça o Passo 2
    RemoteSigned = já está configurado → pule para o Passo 3
    Unrestricted = tudo liberado → pule para o Passo 3

  • 2
    Se apareceu "Restricted", execute este comando para liberar:
    Administrador: Windows PowerShell
    PS C:\> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
      Alteração na política de execução Deseja alterar a política de execução? [S] Sim [A] Sim para Todos [N] Não ...
    (padrão é "N"): S
     
    PS C:\>

    📌 Digite S e pressione Enter quando perguntar. Isso permite rodar seus próprios scripts, mas ainda protege contra scripts maliciosos da internet.

📄 Passo 2 — Criar o Arquivo de Perfil
  • 3
    Verificar se o arquivo de perfil já existe:
    Administrador: Windows PowerShell
    PS C:\> Test-Path $PROFILE
      False  
    PS C:\>

    📌 False = perfil não existe ainda → faça o Passo 4
    True = perfil já existe → pule para o Passo 5 (editar)

  • 4
    Criar o arquivo de perfil (se não existia):
    Administrador: Windows PowerShell
    PS C:\> New-Item -Path $PROFILE -Type File -Force
      Directory: C:\Users\Aluno\Documents\WindowsPowerShell   Mode LastWriteTime Length Name ---- ------------- ------ ---- -a--- 27/04/2026 09:30 0 Microsoft.PowerShell_profile.ps1  
    PS C:\>

    📌 O $PROFILE é uma variável especial que o PowerShell já conhece — ela guarda o caminho completo do seu arquivo de perfil automaticamente.

✏️ Passo 3 — Editar o Perfil com o Bloco de Notas
  • 5
    Abrir o perfil no Bloco de Notas:
    Administrador: Windows PowerShell
    PS C:\> notepad $PROFILE
      (O Bloco de Notas abre com o arquivo em branco)  
    PS C:\>

    📌 O Bloco de Notas vai abrir com um arquivo vazio (ou com o conteúdo que já estava lá). O PowerShell continua funcionando em paralelo — as duas janelas ficam abertas!

  • 6
    No Bloco de Notas, digite exatamente este conteúdo:
    # Meu perfil do PowerShell — GSO I 2026
    Set-Alias -Name gs -Value Get-Service
    Set-Alias -Name gp -Value Get-Process
    Set-Alias -Name gl -Value Get-Location
    Write-Host '✅ PowerShell carregado! Boa aula!' -ForegroundColor Green

    📌 O que cada linha faz:
    # comentário — linhas que começam com # são comentários, o PowerShell ignora
    Set-Alias — cria um atalho: digitar gs vai executar Get-Service
    Write-Host — escreve uma mensagem colorida na tela ao abrir

  • 7
    Salvar o arquivo:
    No Bloco de Notas: Ctrl+S → Salvar. Depois feche o Bloco de Notas.
🔄 Passo 4 — Testar o Perfil
  • 8
    Feche o PowerShell e abra novamente como Administrador.
    Quando o PowerShell abrir, a mensagem deve aparecer automaticamente:
    Administrador: Windows PowerShell
    Windows PowerShell Direitos autorais (C) Microsoft Corporation. Todos os direitos reservados.   ✅ PowerShell carregado! Boa aula!  
    PS C:\Users\Aluno>

    ✅ Se a mensagem verde apareceu — o perfil está funcionando! Toda vez que você abrir o PowerShell, ele vai carregar seus aliases automaticamente.

  • 9
    Testar os aliases criados:
    Administrador: Windows PowerShell
    PS C:\> gs
      Status Name DisplayName ------ ---- ----------- Running AudioEndpointBu... Windows Audio Endpoint Builder ... (lista de serviços aparece) ...  
    PS C:\> gp
      Handles NPM(K) PM(K) WS(K) CPU(s) Id SI ProcessName ... (lista de processos aparece) ...  
    PS C:\>

    ✅ Funcionou! Agora você digitando apenas gs lista todos os serviços — em vez de digitar o longo Get-Service. Isso é personalização profissional!

  • 10
    Salve seu relatório com prints de cada etapa:
    Salve como sem08_ex3_SeuNome.docx

💡 Dica Profissional: Você pode adicionar mais aliases ao perfil quando quiser! Abra de novo com notepad $PROFILE e adicione mais linhas de Set-Alias. Profissionais de TI acumulam aliases úteis ao longo dos anos!

🚨 Erro comum: Não é possível carregar o arquivo ... não está assinado digitalmente
Causa: A política de execução ainda está como Restricted.
Solução: Execute novamente o Passo 2: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
