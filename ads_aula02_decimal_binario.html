00 · Por que Binário?
O PROBLEMA QUE O COMPUTADOR PRECISA RESOLVER
  • Eletrônica digital só reconhece com segurança dois estados elétricos: ligado (HIGH / 5V) e desligado (LOW / 0V).
  • Bit — a menor unidade de informação, com exatamente esses dois valores possíveis: 0 ou 1.
  • Sistema binário — base 2, usa apenas os algarismos 0 e 1, e é exatamente isso que um LED pode representar: apagado = 0, aceso = 1.
  • Codificação de dados — qualquer número, letra ou instrução que um computador processa está, no fundo, representado como uma sequência de bits.
💬 POR QUE ISSO IMPORTA HOJE
Hoje vamos construir, literalmente, um "computador em miniatura" que representa números decimais em binário: cada LED é um bit. Isso conecta a teoria de bases numéricas direto com o hardware real que executa essa conversão.
01 · Objetivos de Aprendizagem
OBJETIVOS DA AULA
  • Converter manualmente um número decimal para binário pelo método das divisões sucessivas por 2.
  • Relacionar cada bit a uma potência de 2 (peso binário) e a um LED do circuito.
  • Montar e simular, no Tinkercad, um conversor decimal→binário com Arduino Uno e 4 LEDs.
  • Expandir a solução para 8 LEDs, ampliando a faixa representável de 0–15 para 0–255.
02 · Conteúdo Programático
TÓPICOS ABORDADOS
  • Sistemas de numeração posicional: base decimal x base binária.
  • Algoritmo de conversão decimal → binário (divisões sucessivas por 2).
  • Pesos binários e potências de 2: 1, 2, 4, 8, 16, 32, 64, 128.
  • Circuito LED + resistor limitador de corrente; mapeamento de bits para pinos digitais do Arduino.
03 · Ilustração Animada — Pesos Binários
REPARE NA ANIMAÇÃO

Cada posição de um número binário vale o dobro da posição anterior: 1, 2, 4, 8. Some os pesos das posições marcadas com 1 e você tem o valor decimal. No exemplo ao lado: 1101 → 8+4+0+1 = 13.

04 · Exemplo Resolvido
🧮 EXEMPLO RESOLVIDO — clique para ver a resolução
Converter o número decimal 13 para binário, usando o método das divisões sucessivas por 2 (o mesmo que o Arduino executa no código desta aula).
  1. 13 ÷ 2 = 6, resto 1 (bit menos significativo — vai para o primeiro LED, leds[0])
  2. 6 ÷ 2 = 3, resto 0
  3. 3 ÷ 2 = 1, resto 1
  4. 1 ÷ 2 = 0, resto 1 (bit mais significativo — para de dividir quando o quociente chega a 0)
  5. Ler os restos de baixo para cima: 1101
✅ Resposta: 13 (decimal) = 1101 (binário) → LEDs D4 D3 D2 D1 = aceso, aceso, apagado, aceso

Conversor com 4 LEDs (0 a 15)

RESOLUÇÃO PASSO A PASSO — clique para ver

EX-02 · DESAFIO
Expansão para 8 LEDs (0 a 255)
⏱ 25 min 🎯 Ampliar a faixa de representação
A partir do circuito de 4 LEDs, adicionar mais 4 LEDs e resistores, e adaptar o código para representar números de 0 a 255 (um byte completo).
RESOLUÇÃO PASSO A PASSO — clique para ver
  1. Adicione mais 4 LEDs e 4 resistores de 220 Ω à protoboard, ligados a 4 novos pinos digitais livres (ex.: 2, 3, 4, 5).
  2. No código, troque int leds[4] = {6,7,8,9}; por um array com 8 posições, incluindo os novos pinos.
  3. Ajuste todos os laços que usam i <= 3 para i <= 7 (ou use sizeof para calcular o tamanho automaticamente).
  4. Teste no Monitor Serial com valores como 200, 255 e 128 — o número máximo representável em 8 bits é 255 (11111111).
  5. Discuta: por que 4 bits vão só até 15 e 8 bits vão até 255? (2⁴−1 = 15; 2⁸−1 = 255)
06 · Guia Prático — Passo a Passo no Tinkercad
🔧 ANTES DE COMEÇAR
Acesse tinkercad.com → faça login → Circuits → Create new Circuit. Arraste os componentes do painel direito para a área de trabalho: um Arduino Uno R3, quatro LEDs, quatro Resistores (220 Ω) e uma Breadboard.
🅰️ MONTAGEM — Conversor com 4 LEDs
Reproduza o circuito abaixo: cada LED tem um resistor de 220 Ω em série, ligado a um pino digital do Arduino, e o catodo (perna curta) de todos os LEDs vai ao GND da breadboard.
1

Posicione os LEDs e resistores

Na breadboard, encaixe 4 LEDs (D1 a D4) lado a lado. Para cada LED, coloque um resistor de 220 Ω em série entre o anodo (perna longa) e o pino do Arduino.

2

Conecte aos pinos digitais

Ligue os resistores aos pinos 6, 7, 8 e 9 do Arduino Uno — exatamente os pinos usados no array leds[4] do código. Ligue o catodo de todos os LEDs ao GND do Arduino, pela trilha negativa da breadboard.

3

Cole o código Arduino

Abra o editor de código (modo texto/C++) do Tinkercad e cole o sketch .ino fornecido para esta aula.

4

Rode a simulação e teste

Clique em Start Simulation, abra o Monitor Serial, digite um número de 0 a 15 e pressione Enter. Observe os LEDs acendendo conforme os bits do número.

5

Desafio: vá para 8 LEDs

Repita os passos 1 e 2 com mais 4 LEDs em novos pinos, e adapte o código (ver EX-02) para representar valores de 0 a 255.

Diagrama de referência — Tinkercad: Arduino Uno + 4 LEDs (D1–D4) + resistores de 220 Ω (R1–R4)
// trecho essencial do código — sketch completo fornecido em anexo int leds[4] = {6, 7, 8, 9}; // leds[0] = bit menos significativo (peso 1) void loop() { number = Serial.parseInt(); // lê o número digitado no Monitor Serial i = 0; while (number >= 1 && i <= 3) { int resto = number % 2; // resto da divisão por 2 = o bit atual digitalWrite(leds[i], resto); // acende (1) ou apaga (0) o LED number /= 2; // avança para a próxima divisão i++; } }

09 · Quiz da Aula
MÚLTIPLA ESCOLHA
1. Qual é o bit menos significativo (LSB) do número binário 1010?
O primeiro 1 (da esquerda)
O último algarismo (0, mais à direita)
O segundo algarismo
Não existe LSB em binário
💬 LSB (Least Significant Bit) é sempre o bit mais à direita, de peso 1 — no código, é leds[0].
VERDADEIRO OU FALSO
2. Com 4 LEDs (4 bits) é possível representar números decimais de 0 até 16.
💬 Falso. Com 4 bits temos 2⁴ = 16 combinações possíveis, mas elas cobrem os valores de 0 a 15 (0000 a 1111) — o 16 já precisaria de um 5º bit.
COMPLETE A RESPOSTA
3. Convertendo 9 para binário (4 bits), quais LEDs ficam acesos? Responda só com os pesos, separados por vírgula (ex: 8,2).
💬 9 = 8 + 1 → binário 1001. Acendem os LEDs de peso 8 e peso 1; os de peso 4 e 2 ficam apagados.
MÚLTIPLA ESCOLHA
4. No código do Arduino, o que a linha digitalWrite(leds[i], resto); faz?
Lê o valor digitado no Monitor Serial
Divide o número por 2
Acende (1) ou apaga (0) o LED de acordo com o bit calculado
Reinicia a contagem de i
💬 digitalWrite(pino, valor) define o estado elétrico do pino: HIGH (1, LED aceso) ou LOW (0, LED apagado) — que é exatamente o bit calculado por resto = number % 2.

🎲 DINÂMICA DE SALA — Corrida da Conversão Binária
