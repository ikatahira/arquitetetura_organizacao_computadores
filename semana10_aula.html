📄 Scripts .ps1 — Do Terminal ao Arquivo +20 XP ▾
Scripts PowerShell têm extensão .ps1. Qualquer editor de texto funciona — use o VSCode, o ISE embutido ou até o Bloco de Notas.
Por segurança, o Windows bloqueia execução de scripts por padrão. Libere com Set-ExecutionPolicy RemoteSigned (uma vez, como admin).
Para executar: .\meu_script.ps1 — o .\ indica "nesta pasta". Sem ele, o PowerShell não encontra o arquivo.
🖊️ Qual editor usar para criar scripts .ps1?
📝 Bloco de Notas Simples
Já vem no Windows. Funciona para scripts simples, mas não tem destaque de sintaxe. Salve com extensão .ps1 manualmente.
🪟 PowerShell ISE Nativo
Editor visual integrado ao Windows. Tem realce de sintaxe, painel de saída e depurador básico. Abra pelo menu Iniciar pesquisando ISE.
💙 VS Code Recomendado
Melhor experiência. Instale a extensão PowerShell (Microsoft). Tem IntelliSense, depurador, terminal integrado e destaque de código profissional.
💾 Como salvar um script .ps1 pelo Bloco de Notas
1Abra o Bloco de Notas e escreva seu script normalmente.
2Clique em Arquivo → Salvar como (ou Ctrl+Shift+S).
3Em "Tipo", mude de Documentos de Texto (*.txt) para Todos os Arquivos (*.*).
4No campo do nome, escreva com extensão: meu_script.ps1
5Escolha uma pasta, ex.: C:\Scripts\ e clique em Salvar.
6No PowerShell, navegue com cd C:\Scripts e execute com .\meu_script.ps1
⚠️
Atenção ao salvar: Se você esquecer de mudar para "Todos os Arquivos", o Bloco de Notas vai salvar como meu_script.ps1.txt — com duas extensões! Verifique pelo Explorer com Ver → Extensões de nomes de arquivo ativado.

🔀 If/Else · For · ForEach — Tomando Decisões +20 XP ▾
if/elseif/else — toma decisões. Operadores: -gt maior · -lt menor · -eq igual · -ne diferente.
foreach — percorre cada item de uma lista ou resultado de cmdlet.
for — loop numérico clássico. while — repete enquanto a condição for verdadeira.
EXEMPLO If/Else — alerta de disco cheio
$livreGB = (Get-PSDrive C).Free / 1GB

if ($livreGB -lt 10) {
  Write-Host "🔴 CRÍTICO: apenas $([math]::Round($livreGB,1)) GB livre!" -ForegroundColor Red
} elseif ($livreGB -lt 30) {
  Write-Host "🟡 AVISO: $([math]::Round($livreGB,1)) GB livre" -ForegroundColor Yellow
} else {
  Write-Host "🟢 OK: $([math]::Round($livreGB,1)) GB livre" -ForegroundColor Green
}
Saída — depende do disco do seu PC
🟢 OK: 127.4 GB livre

# Se o disco estivesse quase cheio, apareceria:
🔴 CRÍTICO: apenas 4.2 GB livre!
EXEMPLO ForEach — verificar lista de serviços críticos
$servicos = @('Spooler', 'WinRM', 'Dnscache', 'wuauserv')

foreach ($svc in $servicos) {

  if ($status -eq 'Running') {

  } else {
    Write-Host "✗ $svc — $status ← ALERTA!" -ForegroundColor Red
  }
}

🛡️ Tratamento de Erros — Try / Catch / Finally +20 XP ▾
Sempre use try/catch quando o script pode falhar: arquivo inexistente, serviço que não responde, permissão negada.
$_ dentro do catch contém a mensagem de erro. -ErrorAction Stop força a exceção para ser capturada.
finally sempre executa — seja com sucesso ou com erro. Ideal para limpeza e log de encerramento.
EXEMPLO Try/Catch — lendo arquivo que pode não existir
try {
  $conteudo = Get-Content 'C:\log.txt' -ErrorAction Stop
  Write-Host "✓ Arquivo lido com sucesso!" -ForegroundColor Green
  Write-Host "Linhas: $($conteudo.Count)"
} catch {
  Write-Host "✗ Erro: $_" -ForegroundColor Red
  $_ | Out-File 'C:\erros.log' -Append
} finally {
  Write-Host "Execução finalizada." -ForegroundColor Cyan
}
Cenário A — arquivo existe
✓ Arquivo lido com sucesso!
Linhas: 142
Execução finalizada.

Cenário B — arquivo não existe
✗ Erro: Cannot find path 'C:\log.txt' because it does not exist.
Execução finalizada.
(erro registrado em C:\erros.log)
EXEMPLO Script robusto — verificar e reiniciar serviço com segurança
$nomeServico = 'Spooler'

try {
  $svc = Get-Service -Name $nomeServico -ErrorAction Stop
  if ($svc.Status -ne 'Running') {
    Start-Service $nomeServico
    Write-Host "✓ $nomeServico iniciado!" -ForegroundColor Green
  } else {
    Write-Host "✓ $nomeServico já está rodando." -ForegroundColor Green
  }
} catch {
  Write-Host "✗ Falha: $_" -ForegroundColor Red
}
Saída — serviço já rodando
✓ Spooler já está rodando.
🔧 Por que isso importa para o técnico? Scripts sem tratamento de erros quebram silenciosamente — e o técnico não sabe o que falhou. Com try/catch você cria scripts robustos que informam exatamente o problema, registram o erro em log e continuam funcionando mesmo quando algo inesperado acontece. Isso é a diferença entre um script de estudante e um script de produção.
⚠️
Importante: sem -ErrorAction Stop, erros de cmdlet não são capturados pelo catch! Sempre adicione quando quiser tratar falhas de cmdlets.
🔧 Funções Reutilizáveis — Organize seu Código +20 XP ▾
Funções encapsulam código repetido. Use param() para parâmetros e return para devolver valores.
Convenção: siga o padrão Verbo-Substantivo: Get-InfoPC, Set-Config, New-Backup.
Use Write-Verbose em vez de Write-Host dentro de funções — as mensagens só aparecem com -Verbose.
EXEMPLO Função — verificar status de serviço
function Get-StatusServico {
  param(
    [string]$Nome,
    [switch]$Verbose
  )
  $svc = Get-Service -Name $Nome -ErrorAction SilentlyContinue
  if ($Verbose) { Write-Host "Consultando $Nome..." }
  return $svc.Status
}

# Chamando a função:
Get-StatusServico -Nome "Spooler"
Get-StatusServico -Nome "wuauserv" -Verbose
Saída das duas chamadas
Running

Consultando wuauserv...
Stopped
EXEMPLO Função — inventário do PC em uma chamada
function Get-InventarioPC {
  $os = Get-CimInstance Win32_OperatingSystem
  $ramGB = [math]::Round($os.TotalVisibleMemorySize / 1MB, 1)
  $livreGB = [math]::Round((Get-PSDrive C).Free / 1GB, 1)

  Write-Host "=== INVENTÁRIO DO PC ===" -ForegroundColor Cyan
  Write-Host "PC : $env:COMPUTERNAME"
  Write-Host "OS : $($os.Caption)"
  Write-Host "RAM : $ramGB GB"
  Write-Host "Disco: $livreGB GB livres"
}

M1
Script de Organização Automática por Extensão
Estratégia: Get-ChildItem lista os arquivos, Group-Object -Property Extension agrupa por extensão. Para cada grupo, New-Item cria a subpasta (se não existir) e Move-Item move os arquivos. O parâmetro -Force no New-Item evita erro se a pasta já existir.
# Missão 1 — Organizar arquivos por extensão param([string]$Pasta = 'C:\Temp\Bagunca') $arquivos = Get-ChildItem -Path $Pasta -File foreach ($arq in $arquivos) { $ext = $arq.Extension.TrimStart('.').ToUpper() $dest = Join-Path $Pasta $ext if (-not (Test-Path $dest)) { New-Item -Path $dest -ItemType Directory -Force | Out-Null } Move-Item -Path $arq.FullName -Destination $dest Write-Host "Movido: $($arq.Name) → $ext\" } Write-Host "Organização concluída! $($arquivos.Count) arquivo(s) movido(s)."
Teste seguro: crie uma pasta C:\Temp\Bagunca com arquivos .txt, .jpg e .pdf antes de rodar. Assim você não afeta arquivos reais.
M2
Script com Tratamento de Erros — Relatório CSV de Serviços
Estratégia: try/catch em torno de cada Get-Service captura erros de serviços inexistentes ou sem permissão. Acumulamos os resultados em uma lista e exportamos ao final com Export-Csv.
# Missão 2 — Verificar serviços críticos com tratamento de erros $servicosCriticos = @('WinRM', 'Spooler', 'wuauserv', 'eventlog', 'Dnscache') $relatorio = [System.Collections.Generic.List[object]]::new() foreach ($svc in $servicosCriticos) { try { $s = Get-Service -Name $svc -ErrorAction Stop $relatorio.Add([pscustomobject]@{ Servico = $svc; Status = $s.Status; Erro = '' }) } catch { $relatorio.Add([pscustomobject]@{ Servico = $svc; Status = 'ERRO'; Erro = $_.Exception.Message }) } } $relatorio | Export-Csv -Path '.\relatorio_servicos.csv' -NoTypeInformation -Encoding UTF8 $relatorio | Format-Table -AutoSize
Chave do try/catch: use -ErrorAction Stop para que erros não-fatais (serviço não encontrado) sejam capturados pelo catch. Sem esse parâmetro, o PowerShell apenas exibe o erro e continua — sem entrar no catch.
M3
Função Get-InventarioPC — Relatório em .txt
Estratégia: uma função com param() recebe o caminho de saída opcional. Get-CimInstance Win32_OperatingSystem fornece SO e RAM. Get-PSDrive retorna espaço em disco. Out-File salva o relatório formatado.
# Missão 3 — Função de Inventário do PC function Get-InventarioPC { param([string]$Saida = '.\inventario.txt') $os = Get-CimInstance Win32_OperatingSystem $ramGB = [math]::Round($os.TotalVisibleMemorySize / 1MB, 2) $livreC = [math]::Round((Get-PSDrive C).Free / 1GB, 2) $totalC = [math]::Round((Get-PSDrive C).Used / 1GB + $livreC, 2) $texto = @" ======================================== INVENTÁRIO DO PC — $(Get-Date -Format 'dd/MM/yyyy HH:mm') ======================================== Computador : $($env:COMPUTERNAME) Usuário : $($env:USERNAME) Sistema : $($os.Caption) RAM Total : $($ramGB) GB Disco C: : $($livreC) GB livres / $($totalC) GB total ======================================== "@ $texto | Out-File -FilePath $Saida -Encoding UTF8 Write-Host "Relatório salvo em: $Saida" return $texto } # Chamar a função Get-InventarioPC
Here-string @"..."@: permite escrever texto multilinha com variáveis embutidas sem concatenação. As aspas que abrem devem estar no final da linha @" e as que fecham "@ sozinhas no início de uma linha — sem espaços antes.
