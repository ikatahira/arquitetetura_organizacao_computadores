📋 Documentação Profissional de Scripts +20 XP ▾
Um bom script PowerShell sempre tem: cabeçalho com nome, autor, data, versão e descrição. Comentários em cada seção lógica.
Use o formato oficial Comment-Based Help do PowerShell — permite usar Get-Help .\meu_script.ps1 para ver a ajuda.
<# .SYNOPSIS Script de manutenção preventiva do sistema. .DESCRIPTION Limpa arquivos temporários, verifica serviços críticos e gera relatório de status. .PARAMETER Destino Caminho onde o relatório será salvo. .EXAMPLE .\manutencao.ps1 -Destino "C:\Relatorios" .NOTES Autor: Isaque Katahira | Versão: 1.0 | Data: 2026 #> param( [string]$Destino = "C:\Relatorios", [switch]$WhatIf )
⭐ Avaliação: na Avaliação 2, a qualidade da documentação é um critério de nota. Um script sem comentários perde pontos — mesmo que funcione perfeitamente.
🔄 Automação de Tarefas Administrativas +20 XP ▾
Tarefas comuns que técnicos automatizam: limpeza de temp, verificação de espaço em disco com alertas, criação de usuários em lote, backup de configurações.
Geração de relatórios de inventário, aplicação de configurações padronizadas em novos PCs, verificação de serviços críticos.
function Clear-TempFiles { $pastas = @($env:TEMP, "C:\Windows\Temp") foreach ($pasta in $pastas) { try { $arquivos = Get-ChildItem $pasta -Recurse -ErrorAction SilentlyContinue $arquivos | Remove-Item -Force -Recurse -ErrorAction SilentlyContinue Write-Host "✓ $pasta limpa" -ForegroundColor Green } catch { Write-Warning "Falha em $pasta: $_" } } }
📦 Módulos PowerShell +20 XP ▾
Módulos estendem o PowerShell. Veja instalados: Get-Module -ListAvailable. Instale: Install-Module -Name NomeModulo.
Módulos úteis: PSWindowsUpdate (Windows Update via CLI), ImportExcel (criar .xlsx sem Excel), Carbon (admin Windows).
Galeria pública em powershellgallery.com — mais de 10.000 módulos de terceiros, muitos gratuitos e open source.
✅ Boas Práticas — Checklist Final +20 XP ▾
FAÇA: Verb-Noun para funções, Write-Verbose para debug (ativa com -Verbose), -WhatIf para simular antes de executar.
EVITE: credenciais hardcoded no script, caminhos absolutos sem variáveis, ignorar erros sem tratamento, usar Write-Host dentro de funções.
🏆 Para tirar 10 na avaliação: script funcional + documentação completa + tratamento de erros + parâmetros + geração de relatório. Revise as semanas 08 a 11!
